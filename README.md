# Asya'nın Bahçesi

Tarayıcıda çalışan, etkileşimli ve kurgusal bir kasımpatı bahçesi deneyimi.

## Yerelde çalıştırma

Dosyaları basit bir statik web sunucusuyla açın. Örneğin:

```bash
npx serve .
```

Ardından terminalin gösterdiği yerel adresi tarayıcıda açın.

## GitHub Pages

Proje tamamen statiktir. GitHub Pages ayarlarında `main` dalının kök dizini seçilerek yayınlanabilir.
